MyCareerLens Owner Stats

A private, browser-only bookmarklet to view live drop-off statistics. Visible only to you.

Step 1 — Drag this button to your bookmarks bar:

📊 MyCareerLens Stats

(Click and hold, then drag onto your browser’s bookmarks bar.)

Bookmarks bar not visible? Press Ctrl + Shift + B to toggle it on (Chrome / Edge / Firefox on Windows).
Step 2 — Use the bookmark
Click the new "MyCareerLens Stats" bookmark whenever you want to see live numbers. A popup will show:
  • Visits
  • Starts (people who reached the question wizard)
  • Completions
  • Drop-off before starting, drop-off mid-assessment
  • Completion rates as percentage of visits and percentage of starters
Step 3 — Tip: click the bookmark while you’re on https://rajantonapeai.github.io/mycareerlens/ for best reliability (CORS-friendly origin). It also works from most other pages, but if you ever see "(unavailable)" in the popup, try again from the MyCareerLens site.

Manual install (if drag-and-drop fails)

If your browser blocks drag-and-drop of javascript: bookmarks (some Edge versions do this), install manually:

  1. Right-click your bookmarks bar → Add page…
  2. Name: MyCareerLens Stats
  3. URL: paste the entire contents of bookmarklet_oneline.txt from this folder.
  4. Save.

Privacy & safety

  • The bookmarklet lives only in your browser’s bookmarks bar.
  • Public visitors of MyCareerLens never see this. The public site has no owner-mode code.
  • The data shown comes from public anonymous integer counters. No user data anywhere.
  • To remove: right-click the bookmark, choose Delete. Done.

What it actually does

The bookmarklet runs this JavaScript code (also available in bookmarklet_raw.js):

(async()=>{
  const NS="mycareerlens-prod";
  const u=k=>"https://abacus.jasoncameron.dev/get/"+NS+"/"+k;
  const f=async k=>{try{const r=await fetch(u(k));if(r.status===404)return 0;if(!r.ok)return null;const d=await r.json();return typeof d.value==="number"?d.value:null;}catch(e){return null;}};
  const [v,s,c]=await Promise.all([f("visits"),f("starts"),f("completions")]);
  const N=n=>n===null?"(unavailable)":n.toLocaleString("en-IN");
  const P=(a,b)=>(a===null||b===null||b===0)?"—":((a/b)*100).toFixed(1)+"%";
  const dB=(v!==null&&s!==null)?Math.max(0,v-s):null;
  const dM=(s!==null&&c!==null)?Math.max(0,s-c):null;
  alert("MyCareerLens — Owner Stats\n"
    +"Generated: "+new Date().toLocaleString("en-IN")+"\n\n"
    +"Visits:                  "+N(v)+"\n"
    +"Starts:                  "+N(s)+"\n"
    +"Completions:             "+N(c)+"\n\n"
    +"Drop-off before start:   "+N(dB)+" ("+P(dB,v)+")\n"
    +"Drop-off mid-assessment: "+N(dM)+" ("+P(dM,s)+")\n\n"
    +"Completion rate: "+P(c,v)+" of visits, "+P(c,s)+" of starters");
})();
